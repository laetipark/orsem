# ORSEM 웹

공식 공시, 내부자 소유변동, 뉴스 후보와 운영 상태를 확인하는 React 19 기반 개인용 대시보드입니다. 화면은 사실·출처·권리 상태를 보여주며 자동 매수·매도 추천이나 주문 기능을 제공하지 않습니다.

## 실행

루트 작업 공간에서 의존성을 설치한 뒤 실행합니다.

```bash
npm run dev:web
npm run build -w @orsem/web
npm run test -w @orsem/web
```

Vite는 작업 공간 루트의 `.env`를 읽습니다. 기본 API 경로 접두사는 `/api/v1`이며 개발 서버는 이를 `VITE_API_PROXY_TARGET` 또는 `http://127.0.0.1:3210`으로 전달합니다.

```dotenv
VITE_API_PROXY_TARGET=http://127.0.0.1:3210
VITE_API_BASE_URL=
VITE_FIXTURE_MODE=true
```

`VITE_FIXTURE_MODE=true`는 Vite 개발 모드에서만 적용됩니다. 운영 빌드에서는 이 값이 설정되어도 테스트 데이터 어댑터를 사용하지 않으므로 가짜 데이터가 운영 화면에 나타나지 않습니다.

## 주요 경로

비로그인 첫 화면은 공개 시장 차트와 최신 뉴스입니다. `/markets`, `/companies`, `/news` 및 각 상세 주소는 공개 전용 화면으로 열리고, 승인된 회원은 같은 주소에서 기존 회원 화면을 이용합니다. 보호된 기능은 로그인·승인 후 원래 주소로 돌아오며, 로그아웃하면 공개 홈으로 이동합니다. 승인 대기·거절 계정도 공개 화면을 이용할 수 있습니다.

공개 시장 차트는 미국 국채 2년·10년과 WTI, 뉴스는 Federal Reserve·BLS·EIA의 공개 허용 자료입니다. 종목 검색은 공식 출처로 확인된 기본 정보만 제공하며, 미국 종목은 지원되는 TradingView 위젯을 표시합니다. 국내 차트·네이버 뉴스·공시·이벤트·분석·관심 종목·알림은 로그인 후 이용합니다. 공개 관련 뉴스가 없으면 빈 상태를 표시합니다.

아래는 승인된 회원의 화면입니다.

- `/`: 오늘의 D001~D005, 시장 뉴스·개인 관심종목 소식, 검토·파서·알림 실패, 커넥터 신선도
- `/search?q=...`: 수집된 종목·뉴스·국내외 공시 메타데이터 통합 검색
- `/events`: 검색·필터·커서 기반 이벤트 탐색
- `/events/:id`: 원문 거래, 공시 접수일과 감지 시각, 출처·권리, 정정 계보
- `/companies/:codeOrTicker`: 토스증권 일봉·1분봉과 현재가, 거래·공시·뉴스 마커와 일봉 기준 전후 수익률
- `/watchlist`: 개인·공유 관심 그룹과 소식, 국내·미국 월간 시가총액 상위 20종목 및 원본 출처 조회
- `/reviews`: 낮은 확신도와 정정 연결의 사람 검토
- `/operations`: 수집 소스, 실행 이력, 큐 적체·실패
- `/login`: 카카오 가입·로그인·승인 상태 확인, 관리자 이메일·비밀번호·TOTP 또는 복구 코드 인증

카카오 가입과 서버 연결 방법은 [카카오 로그인 운영](../../docs/KAKAO_LOGIN.md)을 참고하세요. 신규 회원은 승인 대기 상태로 생성되며 관리자가 이용을 승인합니다.

## 반응형 화면과 로딩

상단 헤더에 오늘·이벤트·관심기업 주 메뉴와 통합 검색창을 둡니다. 검토함과 운영 링크는 관리자에게만 하단 메뉴로 표시합니다. 620px 이하에서는 검색창과 주 메뉴를 각각 별도 행으로 재배치합니다. 긴 기업명과 설정 항목은 줄바꿈하며 차트는 컨테이너 크기에 맞춰 다시 그립니다. 밝은 테마와 어두운 테마를 지원합니다.

최초 조회에는 공통 목록 스켈레톤을, 기업·가격 조회에는 차트 배치에 맞춘 스켈레톤을 표시합니다. 페이지 이동 시 헤더와 메뉴를 유지하며, 2초 주기의 백그라운드 갱신에는 기존 차트를 유지합니다. 운영체제에서 동작 줄이기를 켜면 로딩 애니메이션을 멈춥니다.

## 통합 검색

헤더 검색창에 기업명, 종목 코드, 티커, 뉴스·공시 제목을 입력하면 `/search?q=...`에서 종목·뉴스·공시를 함께 찾습니다. 검색 대상은 수집된 DB 메타데이터이며, 아직 수집하지 않은 기사나 공시는 표시되지 않습니다. 종목 결과는 기업 관측 화면으로, 국내외 공시는 서비스 내 공시 상세 화면으로 연결합니다. 관심종목의 공시도 같은 상세 화면으로 연결하며, 분석 전 공시는 분석 대기 상태로 표시합니다. 뉴스 원출처 링크는 새 창에서 열고 참조 정보를 전달하지 않습니다.

기본적으로 분류마다 5개를 보여주며 **검색 결과 더 보기**로 최대 10개까지 늘릴 수 있습니다. 전체·종목·뉴스·공시 탭은 같은 검색 결과를 분류해 보여줍니다. 접수일·게시 시각·최초 관측 시각과 출처·이용 권리를 구분해 표시합니다. 뉴스 응답은 제목·제공 요약·관련 종목·번역 상태 등 메타데이터만 포함합니다. 관리자와 승인된 조회 회원이 이용할 수 있으며, 신규 개인용 소스는 관리자 범위로 제한합니다. 상세 요청·응답 계약은 [통합 검색 API](../../docs/API.md#통합-검색)를 참고하세요.

## 뉴스 자동 번역

허용된 영문 뉴스의 제목과 제공 요약을 한국어로 표시합니다. 현재 원문 해시·출처·이용 권리와 일치하는 번역만 사용하고 **자동 번역** 표시를 붙입니다. 번역이 대기 중이거나 실패하면 원문 메타데이터와 상태를 표시하며, 요약이 없으면 **요약 미제공**으로 표시합니다. DART·SEC 공시와 NAVER 검색 결과는 번역하지 않습니다.

원래 제목·제공 요약·출처·이용 권리·시각과 번역은 별도로 보존합니다. 기사 HTML·본문·이미지를 요청하거나 저장하지 않으며 기사는 원출처에서 확인합니다. 기존 `/news/:id` 주소는 메타데이터의 안전한 원문 URL을 확인해 원문으로 이동합니다. 로컬 Ollama 설정과 저장 계약은 [뉴스 번역 안내](../../docs/NEWS_TRANSLATION.md)를 참고하세요.

## 기업 이름

해외 기업은 관심·최근 조회 범위에서 토스가 제공하는 공식 한글명이 있으면 표시 이름을 보완합니다. 전체 상장사의 이름을 일괄 번역하는 기능은 아닙니다. 기존에 등록한 한국어 이름과 영문명은 보존하며, 아직 수집하지 않았거나 토스가 지원하지 않으면 기존 이름을 보여줍니다. 기업 정보는 정상 수집 후 24시간 재사용합니다. [기업명 동기화 조건](../../docs/OPERATIONS.md#해외-기업의-한글명-보완)을 참고하세요.

## 기업 아이콘

`apps/web/src/components/company-avatar.tsx`가 종목·이벤트·관심 목록의 공통 로고를 표시합니다. `apps/web/src/lib/company-branding.ts`는 API의 종목 식별 정보와 검수 상태로 로컬 이미지·Logo.dev·Brandfetch 후보를 구성합니다. ETF는 상품·운용사 역할과 검수된 매핑을 요구하며, 이용할 후보가 없거나 로딩에 실패하면 자체 아이콘을 사용합니다.

브라우저는 화면에 보이는 로고만 조회하며, 외부 이미지 요청 전에 API에서 공유 예산을 예약합니다. 후보를 순서대로 시도하고 최대 2개의 외부 후보만 요청합니다. API 키와 공급자 활성 설정, 수동 검수, 이미지 로드 성공은 별도로 관리합니다.

출처는 `/sources`에서 연결하는 공개 `/logo-sources` 페이지에 표시합니다. 공급자 조건, 종목 매핑·ETF 역할, 로딩·실패 캐시와 실제 검수 범위는 [종목 로고 문서](../../docs/STOCK_LOGOS.md)를 참고하세요.

## 차트와 현재가

기업 상세 페이지가 보이는 동안 선택한 차트와 현재가를 2초마다 조회합니다. 1분봉을 볼 때는 이벤트 수익률·마커 목록에 사용하는 일봉도 2초마다 조회합니다. API는 저장된 봉과 캐시된 현재가를 반환하고, worker가 토스 공식 API로 갱신합니다. 실제 데이터 시점은 제공자·수신 시각과 `LIVE`/`STALE` 상태로 확인합니다.

차트 가격은 토스증권만 사용합니다. 연결 정보가 없으면 설정 필요 상태를 표시합니다. 일봉은 해당 시장의 거래일을 유지하고, 1분봉 시각은 KST로 표시합니다. 갱신 중에는 사용자의 확대 범위를 유지하며, 현재가 선은 공식 봉의 OHLC 값을 변경하지 않습니다. 연결·운영 방법은 [운영 문서](../../docs/OPERATIONS.md#toss-securities-chart-setup)를 참고하세요.

차트 위 범례는 마우스를 올리거나 터치한 봉의 시가·고가·저가·종가·거래량을 표시합니다. 처음에는 최신 봉을 보여주며, 범례에 키보드 초점을 놓고 좌우 방향키로 봉을 이동할 수 있습니다. `Home`은 첫 봉, `End`·`Esc`와 **최신 봉 보기**는 최신 봉으로 돌아갑니다.

봉을 옮겨도 범례의 표시 공간을 유지해 차트가 위아래로 밀리지 않도록 합니다. 휠로 축소할 때는 조회된 첫 봉부터 마지막 봉까지의 범위에서 멈춥니다.

**지표 설정**에서 단순이동평균(SMA 5·20·60·120봉), 거래량 패널, RSI(Wilder, 7·14·21봉)를 선택합니다. 기본값은 SMA 20과 거래량이며 설정은 해당 브라우저에 저장됩니다. 지표는 조회된 토스 봉을 기반으로 화면에서 계산합니다. 표본이 부족하거나 거래 없는 기록·잘못된 봉으로 계산이 끊기면 값을 만들어내지 않고 `—`로 표시합니다. 지표 전환과 2초 갱신 중 확대 범위는 유지하고 **차트 맞춤**으로 전체 범위를 다시 볼 수 있습니다.

## API·보안 전제

- 목록은 `{ items, nextCursor }`, 단건 조회와 변경 요청은 객체를 직접 반환합니다.
- 오류는 `{ statusCode, code, message, details? }`입니다.
- 세션 응답의 `csrfToken`을 메모리에 보관하고 상태를 변경하는 요청에 `X-CSRF-Token`으로 전달합니다.
- 회원 요청은 `credentials: include`, 공개 `/public` 조회는 `credentials: omit`을 사용합니다. 공개 쿼리는 별도 캐시를 사용하며 세션 확인 지연이나 장애가 공개 화면 진입을 막지 않습니다.
- OpenDART의 `rcept_dt`는 날짜 전용 `rceptDate`로 표시하며 게시 시각을 만들어내지 않습니다. `firstObservedAt`은 실제 감지 시각으로 별도 표시합니다.
- 수량·단가·금액·지분율은 API에서 받은 십진 문자열을 변형 없이 받고, 화면 렌더링 시에만 형식화합니다.

종목 탐색·메뉴·차트와 주소 계약은 [종목 화면](../../docs/COMPANY_SCREEN.md), 뉴스 표시와 임시 캐시는 [뉴스 수집](../../docs/NEWS_COLLECTION.md)을 따릅니다.
