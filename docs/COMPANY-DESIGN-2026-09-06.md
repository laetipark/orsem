## 디자인 기준과 반영 내용

- 사용자가 제공한 차트 이미지와 [Koyfin 모바일 공식 화면](https://www.koyfin.com/mobile-app/), [종목 요약 이미지](https://www.koyfin.com/wp-content/uploads/2025/12/overview-mob-final.png), [모바일 차트 이미지](https://www.koyfin.com/wp-content/uploads/2025/12/graphs-mob-final.png)를 참고했습니다. 작은 종목 헤더, 가격에 가까운 변화율, 화면 폭을 쓰는 차트, 탭으로 전환하는 소식을 적용했습니다.
- [TradingView 모바일 문서](https://www.tradingview.com/charting-library-docs/latest/mobile_specifics/)의 작은 화면에서 도구와 패널을 재배치하는 방식을 참고했습니다. Orsem은 요청에 따라 모바일에서도 OHLC를 항상 표시합니다. 외부 제품의 코드·브랜드·데이터를 복제하거나 Advanced Charts로 교체한 것은 아닙니다.
- `/companies/:id`의 중복 페이지 제목을 없애고 회사명·가격·전일 대비·기준일을 모았습니다. 큰 수익률 카드는 일봉 종가 기준의 짧은 지표 행으로 바꿨습니다.
- PC는 차트 옆 320px 소식 패널을 사용합니다. 공시·이벤트 / 관련 뉴스 / NAVER 탭 중 보이는 영역만 조회합니다. 태블릿·모바일에서는 차트 아래에 소식이 이어집니다. 기업 정보와 이벤트 수익률은 간결한 행으로 배치합니다.
- 차트 범례는 PC 두 줄, 모바일 세 줄입니다. 모바일 OHLC는 네 칸으로 표시하고 긴 숫자는 해당 줄 안에서 스크롤합니다. 선택 값이 바뀌어도 범례 높이를 고정합니다. 지표 설정과 긴 안내는 펼칠 때만 표시합니다.
- 기존 지표 설정, SMA·거래량·RSI, 가격 출처와 권리 표시, 실시간 가격선과 공식 봉의 분리를 유지합니다. 모바일 종목 상세의 공통 헤더 간격도 줄이고 핵심 버튼은 44px 이상으로 유지했습니다.
- 최근 소식 API는 선택적 `limit`을 지원합니다. 기본 3개, 최대 20개이며 범위를 벗어나거나 잘못된 값은 HTTP 400입니다. 그룹 카드의 3개 요약과 KST 7일·공시/이벤트 중복 제외 기준은 유지합니다.

## 확인한 결과

- 웹 전체 Vitest 45개 파일·268개 테스트 통과. 그 안에 차트 17개, 소식 패널 8개 테스트가 포함됩니다. API 관련 18개 테스트와 격리 API 빌드, 웹 TypeScript 검사, 변경 TypeScript 파일 ESLint가 통과했습니다.
- 브라우저 합성 데이터 검증: 1440/1280/768/720/390/360px에서 문서 가로 넘침 없음. 밝은·어두운 테마, 긴 기업명, 빈 소식, 소식 오류·재시도 표시, 세 탭과 NAVER 별도 결과를 확인했습니다. 합성 데이터는 로컬 미리보기 전용이며 운영 DB에 저장하지 않았습니다.
- 390px에서 차트 시작 위치는 화면 위에서 약 360px입니다. 모바일 범례 높이 110px, 가격 차트와 보조 패널을 합친 캔버스 높이 RSI 사용 시 400px, 미사용 시 320px를 확인했습니다. 도구줄·범례·출처는 이 캔버스 높이에 포함되지 않습니다.
- 1440px에서 소식 패널 320px, 차트 구역은 패널을 접으면 1039px에서 1369px로 늘어납니다. RSI를 끈 PC 캔버스는 420px이며 선택 지표와 범례 값이 유지됩니다.
- 실제 운영 HTTP를 관리자·승인 회원의 임시 세션으로 각각 검증했습니다. 국내·미국 종목 상세, 표시 가격, 비교 종가, 일봉 63개, 최근 소식 기본/20개 요청이 모두 200입니다. 소식 건수·날짜·앞부분이 일치하고 `limit=21`은 400, 옛 공유 조회 API는 410입니다. 조회한 국내 표본의 표시 항목은 1개, 미국 표본은 0개였으므로 20개가 찬 목록의 화면은 합성 데이터로 확인했습니다. 임시 세션 2개는 삭제를 검증했습니다.
- 공개 웹, API live/ready는 200입니다. 운영 브라우저는 로그인 화면까지 확인했습니다. 이번 새 화면의 로그인 후 시각 검증은 격리 미리보기로 수행했습니다. 실제 기기의 터치·핀치, OS 브라우저 메뉴의 200% 확대는 미실시입니다. 720px 검사는 1440px 화면의 200% 확대와 같은 CSS 너비를 검증한 것입니다.
