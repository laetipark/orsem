# 종목 상세 모바일 디자인 개선

2026-09-06 · 구현·검증 완료. 15:27 KST [운영 배포 완료](DEPLOYMENT-2026-09-06-COMPANY-MOBILE.md).

## 화면과 사용 흐름

- `/companies/:id`에서 모바일 로고를 복원하고 종목명·시장·코드를 한 줄에 표시합니다. 삼성전자는 320px에서도 이름 전체를 표시하며, 더 긴 이름은 말줄임하고 기업 정보에서 전체 이름을 확인할 수 있습니다.
- 현재가는 크게, 전일 대비 금액·비율은 작게 표시합니다. 기존 시세 선택·국내 종가 대체·비교 기준과 KST 날짜 계산을 유지했습니다.
- 종목명 주변의 영문명·업종·분류 태그는 기업 정보로 옮겼습니다. 미분류는 생략합니다.
- 차트·가격·출처·이벤트 계산 설명은 `?` 버튼으로 열며 실제 날짜·가격 기준일과 출처 표시는 유지합니다. 도움말은 키보드·Escape·바깥 영역 클릭·닫기와 초점 복원을 지원합니다.
- 모바일 차트 맞춤 버튼은 아이콘으로 줄이고 44px 터치 영역을 유지합니다. 뉴스·공시, 이벤트 등락률, 기업 정보 순서와 데스크톱 차트/뉴스 분할을 유지합니다.
- 관심그룹 버튼은 등록 여부와 그룹 수를 표시합니다. 모바일 하단 팝업에서 개인·참여 공유방 그룹을 여러 개 선택하거나 해제하고 **저장**합니다. 읽기 전용 그룹은 잠금 표시하며, 취소하면 변경하지 않습니다.

증권 서비스의 간결한 가격 중심 배치와 목록 설정 흐름을 참고했습니다: [토스증권](https://home.tossinvest.com/ko), [Robinhood 목록 관리](https://robinhood.com/us/en/support/articles/lists/). 로고·브랜드 자산이나 화면을 복제하지 않고 기존 Orsem 구성요소를 사용했습니다.

## 관심그룹 API

- `GET /watchlist-groups/company-memberships/:companyId`: 개인·참여 공유방 전체의 해당 종목 등록 여부, 권한, 종목 수, revision을 조회합니다. 21종목 페이지나 시세·차트 조회를 사용하지 않습니다.
- `PUT` 동일 경로: 변경 그룹의 `{groupId, revision, selected}` 목록을 단일 트랜잭션으로 저장합니다. 기존 다른 종목의 순서를 유지하고 그룹 권한·최신 revision·200종목 상한을 먼저 확인합니다.
- 기존 승인 이용자·공유방 소유자/참여자 검증, CSRF·same-origin 보호와 감사 기록을 재사용합니다. 다른 이용자 비공개 그룹이나 읽기 전용 그룹은 수정할 수 없습니다.
- 계정·회사별 클라이언트 캐시 분리, 권한 회수 시 해당 계정 캐시 제거, GET의 `private, no-store` 및 브라우저 `cache: no-store`를 적용했습니다.
- 저장 응답이 없으면 자동 재전송하지 않고 서버 상태를 조회합니다. PUT은 15초에 중단하고 현재 상태 확인으로 넘어갑니다. 409 충돌은 최신 선택을 확인한 뒤 다시 저장하도록 안내합니다.
- 추가 마이그레이션은 없습니다. 운영 반영 시 기존 관심그룹 v2가 준비된 환경에서 API와 웹 변경을 함께 반영해야 합니다.
