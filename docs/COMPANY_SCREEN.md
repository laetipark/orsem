# 종목 탐색과 상세 화면

`/companies`에서 기업명·종목번호·티커를 검색하고 국내·미국 시장을 선택합니다. 목록은 이름순으로 페이지를 나누며 최근 완료 일봉 종가·등락률·거래량·시가총액·시세 기준일을 함께 제공합니다. 모바일에서는 종목·가격·등락률을 우선 표시합니다.

## 주소와 식별

기본 주소는 `/companies/005930`, `/companies/MSFT`입니다. 국내 영문 포함 코드와 `BRK.B`처럼 점·하이픈을 가진 티커를 지원합니다. 여러 거래소에 같은 심볼이 있으면 `/companies/NASDAQ:MSFT`처럼 거래소를 붙입니다. 상장폐지·기록된 티커 재사용·지원하지 않는 시장은 UUID를 유지합니다.

서버의 `canonicalPath`만 주소 변경에 사용합니다. 검색·알림에 저장된 UUID 주소도 계속 같은 기업을 가리키며, 안전한 경우 상세 화면에서 코드 주소로 연결됩니다. 주소 변경은 메뉴·검색조건·로그인 복귀 상태를 보존합니다. 차트·뉴스·관심그룹 요청과 캐시의 기업 식별자는 응답의 UUID입니다.

## 정보 배치

목록의 제목은 다른 페이지와 같은 공통 제목 영역을 사용합니다. 사이트 헤더·본문·푸터의 최대 너비는 1,480px이며 좌우 여백은 PC 28px, 1,100px 이하 22px, 900px 이하 16px, 620px 이하 12px입니다. 종목 상세 화면에서도 사이트 헤더와 본문 바깥 여백을 바꾸지 않으며, 상세에서 목록으로 돌아와도 제목 위치와 헤더 높이가 유지됩니다.

PC는 상단 종목명·가격·등락률·핵심 수치, 아래 넓은 차트와 오른쪽 뉴스·공시로 구성합니다. 모바일은 가격·핵심 수치·메뉴·본문 순서입니다. 차트 / 일별 시세 / 기업정보·재무 / 이벤트 / 뉴스·공시 메뉴는 `tab` 검색 매개변수에 보존합니다. 일별 시세표만 내부 가로 스크롤을 허용합니다.

기업정보는 시세·기업개요·재무·배당으로 구분합니다. 확인되지 않은 값은 `—`이며 시세 기준일과 재무 보고기간은 영역별로 표시합니다. 코드의 선행 0, 날짜, 통화, 배수와 수량의 형식을 구분합니다. PER은 검증된 연간 보통주 EPS와 일별 종가를 기준으로 계산하며 확인되지 않은 지표를 추정하지 않습니다.

## 차트

TradingView Lightweight Charts에 오르셈이 수집한 토스 일봉·분봉을 표시합니다. 캔들·라인, 1개월·3개월·1년, 이동평균 5·20·60·120, 거래량, RSI를 지원합니다. 기본 설정은 MA 5·20·60, 거래량, RSI(14)입니다. 빠른 이동평균 버튼과 보조지표 설정은 같은 상태를 사용합니다.

표시 기간 전 최대 119개 실제 봉을 계산에 사용하고 결과는 표시 기간으로 자릅니다. 자료가 부족한 지표는 `—`입니다. 캔들·라인 전환, 메뉴 왕복과 화면 크기 변경은 확대 구간을 유지합니다. 최신 봉은 확대 폭을 유지한 채 최신 위치로 이동하며 화면 맞춤은 전체 기간을 표시합니다. 확대 보기는 브라우저 전체화면을 사용하며 지원하지 않는 환경에서는 화면을 채우는 차트로 표시합니다. Esc 또는 닫기 버튼으로 돌아갑니다.

공시·뉴스·거래 이벤트 마커는 일봉에 연결합니다. 이벤트 목록은 얇은 행 구분선으로 나누고 실제 사건일과 발표일을 구분합니다. 현재가 가격선은 공식 봉을 변경하지 않습니다. 지원되는 거래소·심볼에는 TradingView 외부 링크가 있습니다.

외부 위젯은 자체 데이터를 받을 수 없어 국내 시세와 공시 마커를 위한 기본 차트로 사용하지 않습니다. 시장 지수 위젯의 데이터는 자체 수집 시세와 구분합니다. [위젯 데이터 안내](https://www.tradingview.com/widget-docs/faq/data/), [아시아 지원 시장](https://www.tradingview.com/widget-docs/markets/asia-pacific/).

## 뉴스

관련 뉴스는 제목 한 줄·제공 요약 한 줄·관련 종목을 표시하고 원문으로 연결합니다. 기사 본문은 요청·저장하지 않으며 허용된 해외 소스의 제목·요약만 번역합니다. 네이버 기사는 제공 순서와 원제목을 유지합니다. [수집·캐시 정책](NEWS_COLLECTION.md)을 따릅니다.
