## 측정·도입 판정의 한계

`elapsedMs`는 분할된 평가 작업의 어댑터 호출부터 출력 검증까지 측정한 시간의 합이다. 분할 목록 생성·체크포인트 저장·운영 DB 저장·실제 BullMQ 대기·서비스 계층 재시도는 포함하지 않는다. cold에는 해당 모델 준비 시간이 추가된다. 합성 12개 입력은 과거 실제 12개 입력의 재현이 아니며 기사 표본의 분모에 포함하지 않는다.

실제 뉴스 API의 비인증 확인은 HTTP 401을 반환했다. 인증된 사용자 요청의 기준·평가 p95는 측정하지 못했으며 readiness p95로 대신 합격 처리하지 않는다. 사람의 의미 검수와 개별 모델·내장 문장 분리 가중치의 이용 조건 확인도 완료되지 않았다. 표본 범위, 의미 품질, 전체 성능, 실제 사용자 API 영향, 권리 근거가 채워질 때까지 HOLD를 유지한다.
