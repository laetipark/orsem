# 월간 시장 시총 상위 종목

국내·미국 각각 20개 대표 종목을 토스증권 Open API의 월간 조회 자료로 선정합니다. 공개 [공식 API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)의 전체 종목, 종목 정보, 가격 GET만 사용하며 기존 OAuth 공유 캐시와 요청 간격을 따릅니다. 시총 순위를 제공하지 않는 거래량·거래대금 랭킹으로 대체하지 않습니다.

## 범위와 계산

- 국내 KOSPI·KOSDAQ·KR_ETC, 미국 NASDAQ·NYSE·AMEX의 토스 제공 활성 종목 전체를 조회합니다. 전체 거래소의 모든 상장 상품을 포괄한다고 표시하지 않습니다.
- 보통주이며 `securityType=STOCK`인 종목을 대상으로 합니다. ETF·ETN·우선주·ADR 등은 제외합니다. 제공자 분류와 달리 이름에 채권·우선주·워런트가 명시된 상품도 제외하며 원본과 제외 근거를 보존합니다. ADR 발행주식수의 예탁증권 환산 단위는 명세에서 확정할 수 없어 추정하지 않습니다.
- 발행주식수와 최종 제공 거래가를 곱합니다. 시간외 거래가가 포함될 수 있으므로 종가라고 표시하지 않습니다. 계산·정렬은 정수 연산으로 소수점 아래 12자리까지 보존하고, DB 시총 필드에는 합산 후 원·달러 미만을 버린 정수를 기록합니다. 원본 가격과 구성 종목별 정밀 계산값은 별도로 보존합니다.
- 국내는 기존 DART 법인번호, 미국은 기존 CIK를 우선 사용하고 US·CA ISIN에 포함된 CUSIP 발행자 코드로 보통주 클래스를 합산합니다. 같은 발행자 코드의 CIK가 충돌하면 갱신하지 않습니다. 가장 큰 클래스를 대표 종목으로 표시하며 기업 마스터 식별자는 변경하지 않습니다.
- CUSIP 첫 여섯 자리는 [공식 CGS 문서](https://www.cusip.com/pdf/Processes%20-%20CUSIP_Template_2019.pdf)의 발행자 구분을 따릅니다. CIK가 없는 서로 다른 발행자 코드나 외국 ISIN의 동일 기업 여부는 확정하지 않습니다. 상위 40개 계산 후보와 그룹 근거를 원본에 남깁니다.
- 시각 미제공이나 14일보다 오래된 가격은 제외 사유를 기록합니다. 보통주로 확인한 종목의 가격·발행주식수가 0이면 실제 시총 상한을 알 수 없으므로 전체 갱신을 중단합니다. 제외 종목의 확인 가능한 시총을 같은 발행자별로 합산했을 때 20위 이상일 수 있거나 선정 기업의 다른 클래스가 제외되면 전체 목록 갱신을 중단합니다.

## 갱신과 보존

KST 새 달의 첫 점검부터 수집하며 부팅 때도 점검합니다. 점검은 5분마다 하되 같은 달의 정상 목록이 있으면 API를 호출하지 않습니다. 실패 후에는 6시간 간격으로 재시도합니다. 휴일이나 시간외 최종 거래가도 출처 시각 그대로 보존하므로 거래일을 임의로 만들지 않습니다.

지역별 DB 잠금 아래 전체 응답·식별·통화·중복·정밀도 검증을 마치고 스냅샷과 20개 구성원을 한 트랜잭션에 저장한 뒤 활성 스냅샷 포인터를 바꿉니다. 응답 누락·급감·검증 실패 시 이전 정상 목록을 유지합니다. 수동 운영 관심 테이블, 개인 관심 그룹, 기업 식별자, 공시 원본은 수정하지 않습니다. 대표 40개를 읽는 `market_leader_watchlist` 뷰는 화면과 시세 목록에 사용합니다. 뉴스·공시 수집과 알림의 `market_leader_company_links` 뷰는 원본에 보존된 `components.companyId`와 종목 코드를 현재 상장 기업 정보와 대조한 뒤 같은 기업의 다른 보통주 클래스까지 포함합니다. 이번 실제 자료의 범위는 42개이며 이전 스냅샷에 클래스 ID가 없으면 대표 종목만 유지합니다. 기사 자체의 관련 기업 ID나 기업 마스터를 대표 종목으로 바꾸지는 않습니다.

`market_cap_snapshots.raw_json`에는 `selectionMonth`, `sourceName`, `method`, `providerScope`, `issuerMethod`, `issuerLimitations`, 통화, 관측 시각, 출처 URL·권리 모드, 전체 종목/정보/가격 응답, 제외 내역, 품질 경계와 클래스 구성원을 보존합니다. 각 클래스의 검증된 `companyId`도 기록하여 나중에 티커가 재사용되더라도 다른 회사로 연결하지 않습니다. `basis_date`는 선정 종목 중 가장 최근 제공 거래가의 시장 현지 날짜이며 월간 조회 시각은 `observed_at`으로 구분합니다.

화면과 시세 목록은 대표 40개를 유지합니다. 뉴스·공시·봇 알림은 `market_leader_company_links`에서 검증된 클래스까지 확인하므로 알파벳의 GOOG/GOOGL과 버크셔 해서웨이의 BRK.A/BRK.B를 함께 포괄합니다. 실제 뉴스의 관련 종목 ID는 변경하지 않습니다. 기존 대기 알림도 수신 시점의 활성 목록을 확인합니다.

## 읽기 전용 확인

격리 후보에서는 `python3 scripts/worker.py cli preview-market-leaders`로 계산 결과를 확인합니다. 운영에서는 아래 명령으로 설치된 wheel을 선택합니다. 정기 워커나 스케줄러를 시작하지 않으며, 쓰기 옵션도 없습니다. 실제 토스 조회와 기업 SELECT를 사용하고 월간 목록·알림·큐를 변경하지 않습니다. 공급자 요청과 기존 인증 캐시는 사용할 수 있습니다. 자격 증명은 기존 외부 설정으로 전달합니다. [Python CLI 안내](PYTHON_WORKER.md#운영-cli)를 참고하세요.

```bash
export ORSEM_REPO_ROOT="$PWD"
../orsem-data/worker/current/bin/python -I -B -m orsem_worker.cli preview-market-leaders
```

2026-09-07 KST 실제 전체 자료를 이용한 격리 검증에서 국내 4,307개 중 보통주 2,603개, 미국 10,560개 중 분류 모순을 제외한 보통주 5,037개를 확인했습니다. 정보·가격 배치 응답 누락은 없었고 평가 불가 발행주식수는 최종 범위에서 0개였습니다. 시각 미제공 제외군의 확인 가능한 최대 시총은 국내 약 1.16조 원(20위 약 37.09조 원), 미국 약 529억 달러(20위 약 5,067억 달러)로 경계보다 작았습니다. 상위 40개 클래스 감사에서 알파벳과 버크셔 해서웨이가 각각 두 보통주 클래스로 합산되었습니다. 이는 읽기 전용 계산 확인이며 운영 적용 기록과 구분합니다.
