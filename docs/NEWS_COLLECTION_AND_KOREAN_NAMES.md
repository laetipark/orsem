- 토스증권: 국내·미국 개별 종목 정보·시세·차트에 사용한다. 현재 공식 REST/실시간 API에는 뉴스 조회 기능이 없다.

## 뉴스 데이터와 출처

[이투데이 공식 RSS 안내](https://www.etoday.co.kr/rss/)의 비상업적 이용 조건을 기준으로 로그인한 이용자의 RSS 리더에 연결한다. 이 설정은 상업적 재배포나 영구 아카이브에 대한 허락을 뜻하지 않는다.

기사 제목·원문 링크·언론사·발행 시각만 표시한다. 본문이나 RSS 설명을 저장하지 않으며, 새 RSS 기사를 알림·AI 번역 파이프라인에 넣지 않는다. `STORE_METADATA_ONLY`와 이용 근거 URL, `NONCOMMERCIAL_RSS_READER`, 원래 제목·링크·GUID·발행 문자열을 메타데이터에 보존한다. 날짜에 시간대가 없으면 발행 instant를 추정하지 않는다. 수집 시각과 발행 시각은 별개다.

기사 URL 해시로 중복을 판별하고 재수집 시 최초 관측 시각을 유지한다. 부분 실패·전체 실패를 구분하며 `/sources/freshness`의 `news_rss`는 실제 수집 결과를 표시한다. 상태 조회 자체가 수집 시각을 갱신하지 않는다. 수집은 HTTPS/DNS 검증, 시간 제한, 응답 크기·XML 복잡도 제한을 적용한다.

2026-09-04 23:38 KST 운영 검증에서 당시 피드의 **3건**을 적재했다. 바로 다시 수집했을 때 신규 0건, 최초 관측 변경 0건이었다. 본문·요약·원본 파일·AI 번역·푸시 생성은 모두 0건이었다. 30분 반복 작업 1개와 다음 실행 2026-09-05 00:00 KST를 확인했다. 피드의 제공 항목 수는 요청 시점에 따라 달라진다.

BullMQ의 현재 반복 목록은 원래 `jobId` 대신 MD5 키를 반환하므로, 일정 정체성은 작업 이름·원래 ID·시간대·주기를 조합한 키와 함께 확인한다. 같은 30분 주기를 쓰는 기업 IR 일정과 RSS 일정을 구분하며 비활성화 시 RSS 일정만 제거한다.

## 미국 종목 한글명

토스 공식 `GET /api/v1/stocks/all`의 시장별 지원 목록과 기존 기업의 거래소·티커를 대조하고, `GET /api/v1/stocks`의 `name`에 한글이 있으면 표시 이름으로 사용한다. `englishName`은 기존 영문명이 없을 때 보완하며 기존 영문명·티커 검색은 유지한다. 토스에서 가져온 이름은 같은 출처로 갱신할 수 있고 별도로 등록한 한글명은 보존한다.

종목 정보 캐시는 24시간이다. 기존 캐시를 사용할 때도 기업의 한글명이 빠져 있으면 복구하지만, 공급자 관측 시각은 새 시각으로 바꾸지 않는다. 이름 수집만으로 실시간 시세 구독을 활성화하지 않는다. 공유 OAuth 토큰과 Redis 호출 제한을 사용한다.

공급자의 한글명이 없거나 거래소·티커를 확실하게 대응할 수 없는 종목은 기존 이름을 유지한다. 임의 번역이나 음역은 하지 않는다. 기존 ISIN과 다른 응답은 티커 재사용 가능성이 있어 적용하지 않는다. Alpaca 종목 목록 갱신도 기존 한글명을 덮어쓰지 않는다.

기존 미국 종목 8,766개 중 토스 시장별 목록과 일치하는 6,883개를 조회했다. 공식 목록 3회와 종목 정보 69회 요청을 사용했고 새 OAuth 토큰 발급은 없었다. 한글명 보유 종목은 **2개에서 5,309개**로 증가했다(5,307개 이름 변경). 일치 종목 중 1,574개는 공급자가 한글명을 주지 않았고, 1,883개는 기존 거래소·티커와 공식 목록이 일치하지 않아 적용 대상에서 제외했다. 제외를 곧바로 토스 거래 불가나 상장폐지라고 해석하지 않는다.
