# 뉴스 제목·요약 한국어 번역

뉴스는 제공자가 공개한 제목과 요약만 저장·표시하고 기사는 원문 페이지로 연결합니다. 기사 페이지 요청, 본문 추출·저장·번역과 관리자 본문 편집은 중단했습니다. DART·SEC 공시 원본과 공시 AI 분류는 별도 기능으로 유지합니다.

## 입력과 권리

`IR`, `NEWS_RSS`의 영문 제목과 제공 요약만 번역합니다. 등록된 소스 정책의 `metadataStorageAllowed`, `displayAllowed`, `aiAllowed`가 모두 `true`이고 정책과 실제 권리 모드가 일치해야 합니다. 대상 권리 모드는 `OFFICIAL_PUBLIC_DATA`, `PRIVATE_DISPLAY_ONLY`입니다. 본문 보유 여부와 `fullTextStorageAllowed`는 제목·요약 번역의 조건이 아닙니다. 원래 소스 정책은 변경하지 않습니다.

NAVER 결과는 DB·로그·AI·알림에 넣지 않습니다. 미검토 소스, `LINK_ONLY`, `NO_REDISTRIBUTION`, 불명확한 정책은 번역하지 않습니다. 입력은 제목 최대 1,000자, 제공 요약 최대 1,000자, 유효한 티커 최대 20개입니다. 요약이 없으면 `null`을 유지하며 본문이나 제목으로 요약을 만들지 않습니다.

숫자·날짜·금액·티커와 한국어 출력 검증을 유지합니다. 제목·요약 번역이 실패하면 한 번 제목만 재시도합니다. 이 검사는 모든 오역을 검출하거나 사실의 정확성을 보증하지 않습니다.

## 저장과 목록

원제목·원요약·출처·권리·원본 해시·발행 시각·최초 관측 시각은 보존하고 자동 번역과 처리 이력은 `source_items.translation_json`에 별도로 저장합니다. 과거 번역의 실제 제공자와 모델 기록도 유지합니다. 새 번역의 제공자는 `LOCAL`이며 외부 번역 공급자로 자동 전환하지 않습니다.

목록·검색·종목·개인 소식은 제목 한 줄과 요약 한 줄을 표시하고 원문 링크를 엽니다. 유효한 번역이 없거나 실패·대기 중이면 원문 메타데이터와 상태를 표시합니다. 요약이 없으면 `요약 미제공`으로 표시합니다. 본문 번역 완료 여부로 뉴스 공개나 검색을 차단하지 않습니다.

기존 관리자 수정본의 제목·요약은 `manual_translation_json`의 `version: 2`로 보존합니다. `revisionId`, `sourceHash`, `editedAt`, `editedByAdminId`와 수정 이력의 메타데이터가 일치해야 표시합니다. 본문 해시는 이 형식의 유효성 조건이 아닙니다. 자동 번역은 수동 메타데이터를 덮어쓰지 않습니다. 기존 본문 편집 조회·저장 경로는 종료하며 브라우저의 이전 본문 초안도 제거합니다.

## 설정과 재시도

| 환경 변수                     | 기본값                   | 의미                           |
| ----------------------------- | ------------------------ | ------------------------------ |
| `NEWS_TRANSLATION_ENABLED`    | `false`                  | 제목·요약 번역 활성화          |
| `OLLAMA_URL`                  | `http://127.0.0.1:11434` | 루프백 Ollama 주소             |
| `NEWS_TRANSLATION_MODEL`      | `qwen3.5:4b-q4_K_M`      | 로컬 모델                      |
| `NEWS_TRANSLATION_BATCH_SIZE` | `3`                      | 회차별 최대 메타데이터 작업 수 |
| `NEWS_TRANSLATION_TIMEOUT_MS` | `120000`                 | 번역 호출 한 번의 제한 시간    |

기본 1분 주기로 실행하고 고유 claim ID·원본 해시·시도 시각을 비교해 결과를 저장합니다. 같은 원문 버전의 완료본은 큐 재시도나 모델 변경으로 재생성하지 않습니다. 피드 GUID 등 부가 메타데이터만 변하고 제목·요약·티커가 같으면 기존 번역과 생성 시각을 유지하고 해시 연결만 갱신합니다.

실패 시 기존 지연 재시도와 claim 만료를 유지합니다. 이전 배치 작업을 재실행해도 본문 테이블을 선택하거나 완료 조각을 재개하지 않습니다. DB 저장 전에 프로세스가 종료되는 경우 추론은 다시 실행될 수 있습니다.

Ollama의 루프백 주소, 클라우드 모델 거부, `OLLAMA_NO_CLOUD=1`과 서버의 기존 메모리 회수 설정을 유지합니다. API 키는 필요하지 않습니다.

## 기존 본문 정리와 배포 순서

`UseNewsMetadataOnly1788411000000`은 운영 뉴스 테이블에만 적용하는 재실행 가능한 마이그레이션입니다. `synchronize=false`를 유지합니다.

1. 구 API·discovery·translation worker를 정지하고 진행 중 쓰기 작업이 종료됐는지 확인합니다. 이전 코드가 마이그레이션 뒤 본문을 다시 쓰지 못하도록 해야 합니다.
2. 메타데이터 전용 API·worker·웹을 빌드·검증하고 호환되는 버전을 배치합니다. 웹은 기존 본문 초안을 삭제합니다.
3. 마이그레이션으로 `news_article_contents.blocks_json`, 본문 자동 번역 JSON 전체(`completedChunks` 포함), 본문 수동 번역 JSON을 비웁니다. 기존 행은 `PURGED`로 표시하고 재시도 예약을 제거합니다. 해시·권리·기존 관측/처리 시각은 보존합니다.
4. 원본별 수동 제목·요약과 수정 이력의 메타데이터를 버전 2로 바꾸고 본문 JSON과 메타데이터 내부 본문 해시 의존성을 제거합니다. 현재·이전 수정본의 제목·요약·관리자·시간·revision ID와 source hash, 기존 자동 메타데이터 번역은 보존합니다.
5. 새 서비스를 시작하고 본문 행 증가 없음, 메타데이터 번역·원문 이동·공시 원본 보존을 확인합니다.

정리 대상은 `IR`, `NEWS_RSS`, `GDELT`, `ALPACA_NEWS`, `NAVER` 뉴스입니다. DART·SEC 공시 테이블과 공시 원본은 제외합니다. 과거 백업·비공개 재번역 검토 자료는 삭제하거나 수정하지 않습니다. 2026-09-05 재번역·검수 기록은 당시의 본문 기반 기능에 대한 역사적 기록이며 현재 실행 경로가 아닙니다. 이 문서는 마이그레이션 적용 완료를 의미하지 않으며 실제 배포 기록에서 확인해야 합니다.
