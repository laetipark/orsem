# 뉴스 자동 한국어 번역

사이트 본문으로 이용할 수 있는 영문 뉴스에 한국어 제목과 전문 번역을 추가합니다. 원래 제목·본문을 덮어쓰지 않으며, 자동 번역은 새로운 사실이나 검증 결과로 취급하지 않습니다. 공시 분류, 증거 등급, 거래 방향, 원문 URL과 이용 권리도 바꾸지 않습니다. DART·SEC 공시는 이 기능의 번역 대상이 아닙니다.

## 현재 서버 설정 — 2026-09-05 확인

실행 중인 worker는 **로컬 Ollama의 Qwen 4B**를 사용합니다. 기존 `.env`와 실행 중인 프로세스에서 확인한 번역 관련 값은 다음과 같습니다. 비밀 값은 표시하지 않습니다.

```dotenv
NEWS_TRANSLATION_ENABLED=true
OLLAMA_URL=http://127.0.0.1:11434
NEWS_TRANSLATION_MODEL=qwen3.5:4b-q4_K_M
NEWS_TRANSLATION_BATCH_SIZE=3
NEWS_TRANSLATION_TIMEOUT_MS=120000
```

번역 큐는 매분 실행되며 회차마다 제목·요약 최대 3건과 본문 최대 3건을 순차 처리합니다. 120초는 호출 한 번의 제한이며 기사 전체 처리 시간 제한이 아닙니다. 원문과 유효한 완료 번역은 보존하고 다른 제공자로 자동 전환하지 않습니다. 새 자동 번역을 끄는 설정은 `NEWS_TRANSLATION_ENABLED=false`이며, 기존 번역 삭제나 별도 공시 AI 분류 설정 변경을 뜻하지 않습니다. 환경 파일 수정은 실행 중인 worker에 자동 반영되지 않으므로 적용 시 환경 재로드와 재시작이 필요합니다.

뉴스 번역은 `LocalNewsTranslationClient`를 직접 사용합니다. Azure 연결 어댑터·제공자 선택·자격 증명 읽기·월별 문자 예약 기능은 삭제했습니다. 제공자 선택 환경 변수 없이 로컬 번역만 실행합니다. 아래 문서의 조각 재사용·관리자 수정본 보호는 최신 worker 소스의 기능이며, 현재 운영 빌드와 구분해야 합니다.

Ollama는 루프백 주소, `OLLAMA_NO_CLOUD=true`, 동시 요청 1개, 상주 모델 최대 1개, 문맥 4096, 유휴 해제 5분으로 실행 중입니다. Argos·TranslateGemma·DeepL·Google·LibreTranslate는 운영에 연결돼 있지 않습니다. 평가 때 강제한 CPU 4스레드·GPU 미사용 옵션과 임시 큐 감시 도구도 운영 설정이 아닙니다.

[로컬 비교 결과](LOCAL_TRANSLATION_EVALUATION_2026-09-05.md)에 따라 모델 교체는 보류했습니다. 일회성 평가 코드는 소스·테스트·실행 가이드를 외부 데이터 폴더에 보존한 뒤 저장소에서 정리했습니다. 공통 결과 검증은 `news-translation-validation.ts`로 분리했으며 검증 규칙과 번역 프롬프트는 유지했습니다. 이 소스 정리 과정에서 운영 설정이나 프로세스는 변경하지 않았습니다.

### 2026-09-05 문제 기사 재번역

사용자의 Qwen 재번역 요청에 따라 저장 기사 86건을 조사하고, 오류가 확인된 필드와 짧은 실패 기사부터 31건을 보정했습니다. Qwen 후보 51개를 생성한 뒤 원문과 대조하는 에이전트 검수로 언어 혼입·요일/오후 누락·은행명·인명·직책·금액·문단 누락을 수정했습니다. 사람 검수나 모델 자체의 품질 개선을 입증하는 결과는 아닙니다.

제목·요약 31건과 본문 16건(175블록)을 동일한 구조·언어·사실 검사로 검증하고 한 트랜잭션에서 번역 JSON만 갱신했습니다. 원문·권리·해시·현재 번역을 잠금 상태에서 대조했으며, 다른 입력이나 수동 수정이 있으면 반영을 중단하도록 했습니다. `repair` 기록에 생성 모델·에이전트 보정·계획 해시를 남겼습니다.

23:20 KST의 별도 조회에서 저장값 일치, 원문 보존, 운영 API 번역 읽기 성공을 확인했습니다. 본문 완료는 26건에서 32건으로 늘었고, 긴 본문 실패 54건은 이번에 처리하지 않아 미완료 상태로 유지합니다. 두 AI 큐는 `paused=false`, 활성 작업 0개였으며 준비 상태는 HTTP 200이었습니다. 모델·운영 빌드·프로세스·DB 스키마는 바꾸지 않았습니다.

원문 스냅샷·이전 번역·Qwen 후보·교정본·적용 전후 값·검증 기록은 [비공개 보존 폴더](/home/laeti/orsem-data/translation-repairs/20260905-qwen-reviewed/README.md)에 있습니다. 기존 번역을 복원할 때도 원문 해시와 현재 번역이 적용 후 값과 일치하는지 먼저 확인해야 합니다.

## 화면 표시

뉴스 목록·검색·기업 페이지의 카드에는 한국어 번역 제목과 번역 요약만 표시하고 **자동 번역** 표시를 붙입니다. 관리자 수정본은 **관리자 수정**으로 구분합니다. 번역 요약이 없으면 원문 요약으로 대체하지 않고 생략합니다. 상세 화면은 **번역 / 원문** 선택으로 제목·요약·본문을 함께 전환하며 선택한 본문만 표시합니다. 새 기사는 번역으로 시작하고, 한국어 원문에는 언어 전환을 표시하지 않습니다. 출처 링크와 발행·최초 관측 시각은 두 언어에서 동일하게 유지합니다.

영문 기사는 제목과 본문 번역이 모두 현재 원문 해시와 일치할 때만 `/news`에 표시합니다. 처리에 실패하면 원문을 공개 목록에 먼저 내보내지 않고 재시도합니다. 자동 번역은 오역이나 누락이 있을 수 있으므로 상세 화면에서 원문을 함께 확인할 수 있습니다.

## 처리 범위와 보존

입력은 검토된 콘텐츠 프로필을 통해 저장한 제목과 본문입니다. `fullTextStorageAllowed`, `displayAllowed`, `aiAllowed`가 모두 `true`이고 권리 모드가 `OFFICIAL_PUBLIC_DATA` 또는 로그인 개인 화면용 `PRIVATE_DISPLAY_ONLY`인 경우만 처리합니다. `STORE_METADATA_ONLY`, `LINK_ONLY`, `NO_REDISTRIBUTION`과 권한이 불명확한 소스는 수집·번역·응답에서 제외합니다. 번역 결과에도 원래 이용 권리와 출처 제한이 그대로 적용됩니다.

현재 소스 허용 목록은 Samsung Global, Federal Reserve, BLS입니다. NAVER, GDELT, 이투데이, Microsoft IR과 미검토 RSS·IR은 번역 대상이 아닙니다. 본문 언어를 판별해 영문 기사만 처리하고, 긴 전문은 문단 경계에서 제한된 크기로 나눕니다. 큰 목록은 항목 묶음별로 처리한 뒤 원래 목록 구조로 합칩니다. 각 블록의 순서와 필수 한국어, 숫자·날짜·금액·티커를 검사하지만 이 검사가 모든 오역을 찾아낸다는 뜻은 아닙니다.

공통 결과 검사는 값이 있는 요약에도 적용합니다. 영문 고유명사·주소·PDF 표지를 허용하면서 지배적인 영문 잔존과 다른 언어 혼입, 극단적인 본문 축약을 차단합니다. 숫자는 혼합분수·백분율 범위·한국어 금액 단위의 동등 표기를 비교하고, 명시된 월·요일·오전/오후·EDT/EST와 통화 변경도 확인합니다. 의미상 동등한 모든 자연어 표현을 인식하는 검사는 아니며 부정·조건·기관명·수치의 주체까지 보증하지 않습니다. 실제 저장 번역의 대조 결과와 이 변경의 운영 반영 상태는 [번역 품질 검증 보고서](TRANSLATION-QUALITY-2026-09-05.md)에 기록합니다.

후속 반기 검사는 명시 연도와 붙어 있는 `H1/H2`·`first/second half`를 해당 연도의 `상반기/하반기`와 비교합니다. 정상 표기를 숫자 누락으로 거절하던 사례를 보정하고, `H2 2026`을 `2026년 2분기`로 잘못 옮긴 결과는 차단합니다. 연도 없는 H1/H2와 제품명 문맥은 기존 숫자 검사에 남기는 보수적인 범위입니다. 2026-09-05 23:36 KST 검증 모듈과 소스맵만 운영 worker에 반영하고 재시작했습니다. 모델·설정·스키마는 유지했으며, 재번역한 제목·요약 31건과 본문 16건의 저장값·원문 보존·운영 읽기를 다시 확인했습니다. 자세한 범위는 [배포 기록](DEPLOYMENT-2026-09-05.md)에 있습니다.

제목 번역은 `source_items.translation_json`, 본문 번역은 `news_article_contents.translation_json`에 별도로 저장합니다. 원문의 제목·본문 블록·원본 응답·해시·출처·게시 시각과 최초 관측 시각은 보존합니다. 완료된 번역도 원문·본문 해시, 정책, 번역 구조와 버전 검증을 통과해야 API에 표시합니다. 로컬 모델 설정을 바꿔도 기존의 유효한 완료본은 유지합니다. 번역 생성 시각 `translatedAt`은 게시 시각이나 최초 관측 시각을 대신하지 않습니다.

## 로컬 번역 실행

새 번역의 제공자는 항상 `LOCAL`입니다. 응답을 크기·시간 제한 안에서 읽고 블록 구조, 한국어, 숫자·날짜·금액·티커 보존을 검사합니다. 연결 실패나 검증 실패 시 기존 지연 재시도를 사용하며 다른 제공자로 자동 전환하지 않습니다.

저장 형식과 API에는 과거 `AZURE` 번역의 실제 출처를 그대로 읽고 표시하기 위한 호환성이 남아 있습니다. 이 값은 연결 옵션이 아니며 새로운 Azure 요청을 실행할 수 없습니다. 연결 삭제를 이유로 저장된 번역을 지우거나 `LOCAL`로 바꾸지 않습니다.

로컬 실행은 외부 번역 API 이용료가 없으며 서버 자원을 사용합니다. Ollama 주소는 루프백으로 제한하고 `OLLAMA_NO_CLOUD=1`를 유지합니다. 마지막 추론 후 5분간 요청이 없으면 모델 메모리를 회수합니다(`OLLAMA_KEEP_ALIVE=5m`). 연속 작업 중에는 유지하고 다음 요청에서 모델 로딩 시간이 추가될 수 있습니다. 공시 AI 분류기는 뉴스 번역 제공자와 별개입니다.

## 설정

아래는 최신 소스의 설정 목록입니다. 로컬 번역에는 외부 번역 API 키가 필요하지 않습니다. 현재 서버의 입력 파일과 활성 기능은 위의 확인 기록을 따릅니다.

| 환경 변수                     | 기본값                   | 의미                                                 |
| ----------------------------- | ------------------------ | ---------------------------------------------------- |
| `NEWS_TRANSLATION_ENABLED`    | `false`                  | 뉴스 번역 활성화                                     |
| `OLLAMA_URL`                  | `http://127.0.0.1:11434` | 로컬 Ollama 기본 주소                                |
| `NEWS_TRANSLATION_MODEL`      | `qwen3.5:4b-q4_K_M`      | 로컬 번역 모델                                       |
| `NEWS_TRANSLATION_BATCH_SIZE` | `3`                      | 회차별 제목 작업·본문 작업 각각의 최대 수            |
| `NEWS_TRANSLATION_TIMEOUT_MS` | `120000`                 | 번역 호출 1회 제한 시간(밀리초), 전문 전체 시간 아님 |

1. 같은 서버의 Ollama에 `NEWS_TRANSLATION_MODEL`에 지정한 로컬 모델을 준비합니다. 루프백 주소와 클라우드 모델 거부 설정을 유지합니다.
2. 위 환경 변수로 모델·배치 크기·호출 제한을 설정하고 `NEWS_TRANSLATION_ENABLED=true`로 활성화합니다. 환경 변경을 적용할 때는 진행 중 번역 완료 후 worker의 환경을 다시 읽어 재시작합니다.
3. 번역 결과의 한국어 제목·본문, 출처·해시 보존을 확인합니다. 설정 존재나 프로세스 시작만으로 연결 성공으로 판단하지 않습니다.

관리자 편집·조각 재사용을 포함한 최신 전체 소스를 운영에 반영하려면 별도의 `AddManualNewsTranslations1788405000000` 마이그레이션과 호환되는 API·worker·웹 배포가 필요합니다. Azure 연결 제거 자체는 DB 마이그레이션이나 기존 행 재작성이 필요하지 않습니다. `synchronize=false`를 유지합니다.

## 중복 처리와 재시도

번역은 별도 큐에서 기본 1분마다 실행하며 회차별로 제목·요약 작업과 본문 작업을 각각 최대 3건 선택합니다. 현재 원문 버전의 유효한 완료본은 재번역하지 않습니다. 피드의 부수적인 메타데이터만 달라지고 실제 제목·요약·티커 입력이 같으면 기존 제목 번역과 생성 시각을 유지하며 원본 해시 연결만 갱신합니다. 본문 해시가 같으면 본문 완료본도 유지합니다. 실제 번역 입력이 바뀌면 새 버전으로 처리하며, 기존 수동 수정본이 있는 기사는 자동 처리 대신 관리자 재검토를 기다립니다.

긴 본문은 완료한 조각을 저장합니다. 뒤쪽 조각이 실패하면 재시도에서 앞의 완료 조각을 재사용합니다. 저장 조각의 입력 해시와 출력 구조·한국어·숫자·티커를 검증하고, 로컬 모델 설정 변경 시에도 유효한 저장 조각을 재사용합니다. 새 조각의 제공자·모델은 별도로 기록하며 완료 후에도 조각별 생성 정보를 남깁니다. 소스→본문 순서로 잠그고 고유 작업 토큰과 원문 해시를 비교해 완료 결과를 저장하므로 이전 작업이나 수집 작업이 새 결과를 덮어쓰지 않습니다.

실패 작업은 기존 지연 재시도를 유지합니다. 로컬 추론에 성공한 직후 DB에 결과를 저장하기 전에 프로세스가 중단되면 해당 조각이 다시 요청될 수 있습니다. 추론과 DB 사이의 원자적 거래가 없으므로 이 좁은 장애 구간까지 정확히 한 번을 보장하지는 않습니다. 저장된 완료본과 완료 조각은 반복 요청하지 않는 것이 보장 범위입니다.

## 관리자 Markdown 수정

관리자 로그인 후 기사 상세에서 **번역 수정**을 엽니다. 최초 편집은 현재 원문과 해시·구조가 일치하는 완료 자동 번역이 있는 영문 기사에 한해 가능합니다. 원문을 옆에서 참고하며 번역 제목·요약·Markdown 본문을 수정하고 미리보기 후 저장합니다. 좁은 화면에서는 원문과 입력을 세로로 배치합니다. 제목, 문단, 목록, 인용, 굵게, 기울임, 인라인 코드, HTTP(S) 링크를 지원합니다. 코드 블록·중첩 목록·원시 HTML·이미지·실행 가능한 링크는 허용하지 않습니다.

수정본은 별도 `manual_translation_json`에 저장하고 수정 이력 테이블에 관리자·시간·원문 해시·이전 값·새 값을 남깁니다. 원문과 자동 번역 JSON은 수정하지 않습니다. 공개 시 수동 값과 이력이 일치해야 하며 현재 원문·권리 검증을 통과해야 합니다. 작업자는 수동 수정본을 자동 덮어쓰지 않습니다.

다른 관리자가 먼저 저장하거나 원문이 바뀌면 저장을 409로 거절합니다. 입력은 유지하며 최신 원문을 다시 읽고 수정할 수 있습니다. 검증된 수동 수정 이력이 있는 기사는 원문 변경으로 공개 번역이 차단되어도 관리자 전용 복구 편집으로 재검토할 수 있습니다. 일반 사용자는 검증되지 않은 번역을 볼 수 없습니다.

작성 중인 초안은 같은 브라우저 탭의 세션 저장소에 관리자·기사별로 저장하며 최근 초안 저장 후 30분 이내에 다시 열면 복원합니다. 만료된 초안은 다시 읽을 때 제거합니다. 로그아웃·계정 변경 시 제거하며 저장 실패나 충돌 시 입력을 유지합니다. 수정 내용이 남은 채 페이지를 닫을 때 경고합니다. 저장 API는 관리자 권한·CSRF·요청 제한을 적용합니다.

## API와 검색

허용된 뉴스의 목록 응답은 제목 번역과 본문 이용 가능 상태만 반환하고, `GET /news/:id`는 원문 블록과 한국어 번역 블록을 반환합니다. 내부 원문 저장 경로와 실패 메시지는 응답에 포함하지 않습니다.

```json
{
  "language": "ko",
  "title": "번역된 한국어 제목",
  "description": null,
  "translatedAt": "2026-09-04T00:00:00.000Z",
  "provider": "LOCAL",
  "model": "qwen3.5:4b-q4_K_M"
}
```

기존 제목·요약 필드는 원문이며, `SourceEvidence.excerpt`의 이용 권리 안내도 유지합니다. 원래 요약을 제공할 수 있는 출처에서는 `SourceEvidence.description`으로 별도 반환합니다. 검색은 기존 기업·원문 제목과 함께 유효하게 저장된 한국어 번역 제목도 찾습니다. 검색 요청 자체가 번역이나 외부 API 호출을 실행하지 않습니다.
