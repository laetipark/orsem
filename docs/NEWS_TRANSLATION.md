# 뉴스 자동 한국어 번역

사이트 본문으로 이용할 수 있는 영문 뉴스에 한국어 제목과 전문 번역을 추가합니다. 원래 제목·본문을 덮어쓰지 않으며, 자동 번역은 새로운 사실이나 검증 결과로 취급하지 않습니다. 공시 분류, 증거 등급, 거래 방향, 원문 URL과 이용 권리도 바꾸지 않습니다. DART·SEC 공시는 이 기능의 번역 대상이 아닙니다.

## 화면 표시

뉴스 목록과 상세 화면에서는 한국어 제목과 본문을 먼저 표시하고 **자동 번역** 표시를 붙입니다. 상세 화면의 **영문 원문 보기**에서 원래 제목과 전문을 펼칠 수 있으며 원출처 링크도 항상 제공합니다.

영문 기사는 제목과 본문 번역이 모두 현재 원문 해시와 일치할 때만 `/news`에 표시합니다. 처리에 실패하면 원문을 공개 목록에 먼저 내보내지 않고 재시도합니다. 자동 번역은 오역이나 누락이 있을 수 있으므로 상세 화면에서 원문을 함께 확인할 수 있습니다.

## 처리 범위와 보존

입력은 검토된 콘텐츠 프로필을 통해 저장한 제목과 본문입니다. `fullTextStorageAllowed`, `displayAllowed`, `aiAllowed`가 모두 `true`이고 권리 모드가 `OFFICIAL_PUBLIC_DATA` 또는 로그인 개인 화면용 `PRIVATE_DISPLAY_ONLY`인 경우만 처리합니다. `STORE_METADATA_ONLY`, `LINK_ONLY`, `NO_REDISTRIBUTION`과 권한이 불명확한 소스는 수집·번역·응답에서 제외합니다. 번역 결과에도 원래 이용 권리와 출처 제한이 그대로 적용됩니다.

현재 소스 허용 목록은 Samsung Global, Federal Reserve, BLS입니다. NAVER, GDELT, 이투데이, Microsoft IR과 미검토 RSS·IR은 번역 대상이 아닙니다. 본문 언어를 판별해 영문 기사만 처리하고, 긴 전문은 문단 경계에서 제한된 크기로 나눕니다. 각 블록의 순서와 필수 한국어, 숫자·날짜·금액·티커·URL을 검사하지만 이 검사가 모든 오역을 찾아낸다는 뜻은 아닙니다.

제목 번역은 `source_items.translation_json`, 본문 번역은 `news_article_contents.translation_json`에 별도로 저장합니다. 원문의 제목·본문 블록·원본 응답·해시·출처·게시 시각과 최초 관측 시각은 보존합니다. 완료된 번역도 원문·본문·정책·모델·프롬프트 버전이 모두 맞아야 API에 표시합니다. 번역 생성 시각 `translatedAt`은 게시 시각이나 최초 관측 시각을 대신하지 않습니다.

## 로컬 실행과 비용

worker가 같은 서버의 Ollama에 요청하여 번역합니다. 외부 번역 API나 유료 클라우드 추론으로 자동 전환하지 않으므로 외부 API 이용료가 발생하는 경로는 없습니다. 서버 CPU·메모리·디스크·전력은 사용하며, 모델 설치에는 다운로드와 저장 공간이 필요합니다. 실행 속도는 서버 자원과 모델 상태에 따라 달라집니다.

Ollama API 주소는 루프백 주소로 제한합니다. 제공하는 PM2 설정은 클라우드 기능을 끄며 모델과 실행 파일은 저장소 밖에 둡니다. 로컬 API와 클라우드 API의 구분, `OLLAMA_NO_CLOUD=1`의 의미는 [Ollama API 안내](https://docs.ollama.com/api/introduction)와 [공식 로컬 실행 안내](https://docs.ollama.com/faq#how-do-i-disable-ollama-cloud-features)를 참고하세요.

## 설정

일반 설정은 [외부 환경 파일](CREDENTIALS.md)에 보관합니다. 번역에는 별도 외부 API 키가 필요하지 않습니다.

| 환경 변수                     | 기본값                   | 의미                                     |
| ----------------------------- | ------------------------ | ---------------------------------------- |
| `NEWS_TRANSLATION_ENABLED`    | `false`                  | 뉴스 번역 작업 활성화                    |
| `OLLAMA_URL`                  | `http://127.0.0.1:11434` | 로컬 Ollama의 기본 주소. `/v1` 없이 사용 |
| `NEWS_TRANSLATION_MODEL`      | `qwen3.5:4b-q4_K_M`      | 설치된 로컬 번역 모델                    |
| `NEWS_TRANSLATION_BATCH_SIZE` | `3`                      | 한 번에 처리할 최대 뉴스 수              |
| `NEWS_TRANSLATION_TIMEOUT_MS` | `120000`                 | 번역 요청 제한 시간(밀리초)              |

1. [로컬 Ollama 설치 절차](DEPLOYMENT.md#로컬-ollama-분류기)에 따라 실행 파일과 모델을 준비합니다. 같은 서버의 기존 Ollama를 재사용할 수 있습니다.
2. 빌드 후 뉴스 번역 저장 컬럼을 추가하는 `AddNewsTranslation` 마이그레이션을 적용합니다. `synchronize=false`를 유지합니다.
3. `NEWS_TRANSLATION_ENABLED=true`와 위 주소·모델을 설정하고 worker·Ollama에 환경을 다시 주입합니다.
4. 정상적으로 저장된 제목·본문 번역이 `GET /news/:id`와 상세 화면에 함께 보이는지 확인합니다. 설정값 존재나 프로세스 시작만으로 번역 성공을 판단하지 않습니다.

번역은 별도 큐에서 정기적으로 처리하며 기본값은 1분마다 최대 3건입니다. 한 번에 기존 뉴스 전체를 번역하지 않고 순차적으로 처리합니다. 영문 대기 항목은 번역이 완료될 때까지 통합 뉴스 목록에서 숨깁니다. 뉴스 번역 활성화는 공시 AI 분류기 `AI_ENABLED`와 별개입니다.

처리 상태와 재시도 시각도 저장합니다. 같은 원문의 완료·건너뜀 결과는 반복 처리하지 않고, 원문 해시가 바뀌면 다시 평가합니다. 실패는 5분·10분 뒤 재시도하고 세 번째 실패부터는 하루 간격을 둡니다. 모델 응답을 기다리던 작업이 중단되어도 점유 시간이 지난 뒤 다시 처리할 수 있습니다. 처리 중 원문이 바뀌면 이전 번역으로 덮어쓰지 않습니다. 번역 이력이 남은 상태에서는 마이그레이션 되돌리기를 거절합니다.

## API와 검색

허용된 뉴스의 목록 응답은 제목 번역과 본문 이용 가능 상태만 반환하고, `GET /news/:id`는 원문 블록과 한국어 번역 블록을 반환합니다. 내부 원문 저장 경로와 실패 메시지는 응답에 포함하지 않습니다.

```json
{
  "language": "ko",
  "title": "번역된 한국어 제목",
  "description": null,
  "translatedAt": "2026-09-04T00:00:00.000Z",
  "provider": "LOCAL",
  "model": "qwen3.5:4b-q4_K_M"
}
```

기존 제목·요약 필드는 원문이며, `SourceEvidence.excerpt`의 이용 권리 안내도 유지합니다. 원래 요약을 제공할 수 있는 출처에서는 `SourceEvidence.description`으로 별도 반환합니다. 검색은 기존 기업·원문 제목과 함께 유효하게 저장된 한국어 번역 제목도 찾습니다. 검색 요청 자체가 번역이나 외부 API 호출을 실행하지 않습니다.
