# 보안 모델

- 로컬 관리자 한 명이 비밀번호·TOTP로 인증합니다. 선택적인 카카오 가입은 별도의 `VIEWER` 계정을 `PENDING` 상태로 만들며, 관리자 계정에 연결하거나 관리자 권한을 부여하지 않습니다.
- 승인 대기·거절 회원은 비공개 데이터를 조회할 수 없습니다. 승인된 조회 회원은 명시적으로 표시된 `GET`/`HEAD` 관측 경로만 사용할 수 있습니다. 데이터 변경, 검토, 운영, IR 소스·회원 관리, 공시 원문 다운로드, 관리자 보안 설정은 관리자 전용입니다. 보호된 요청마다 DB의 현재 계정 상태를 확인하므로 권한 회수는 다음 요청에 적용됩니다.
- 비밀번호는 Argon2id를 사용합니다. TOTP 비밀 값은 암호화하여 저장하고 복구 코드는 해시로 저장합니다.
- 브라우저 세션은 Redis에 저장하고 HttpOnly 쿠키와 `SameSite=Lax`를 사용합니다. 유휴 시간 한도는 12시간, 절대 유효기간은 7일입니다.
- 상태를 변경하는 브라우저 요청에는 세션 CSRF 토큰이 필요합니다. `Origin`이 제공되면 설정된 브라우저 출처와 일치해야 합니다. 공개 로그인·로그아웃 경로도 이 검사를 우회하지 않습니다.
- 카카오 인증은 브라우저 세션에 연결된 5분 유효 `state`와 `nonce`를 사용합니다. `state`는 Redis에서 원자적으로 한 번만 소비합니다. 서버는 카카오의 고정 JWKS 주소로 ID 토큰의 RS256 서명을 검증하고, 발급자·대상·시각·`nonce`를 확인한 뒤에만 회원 세션을 생성합니다. OAuth 인증이나 상태 저장소가 실패하면 인증을 허용하지 않습니다. 인증 성공 시 세션을 재생성하며, 관리자·회원 식별자가 섞인 세션은 거절합니다.
- 카카오 회원 식별에는 ID 토큰의 십진 정수 문자열 `sub`를 사용해 정밀도를 유지합니다. 요청 범위는 `openid`뿐입니다. 선택적인 닉네임은 정리해서 저장하며 이메일과 다른 프로필 속성은 수집하지 않습니다. 액세스·갱신·ID 토큰은 저장하거나 애플리케이션 응답에 노출하지 않습니다. 콜백 코드와 자격 증명을 로그에 남기면 안 됩니다.
- Nginx 템플릿은 정확한 카카오 콜백 경로의 접근 로그를 끄고 `Referrer-Policy: no-referrer`를 설정합니다. 운영 프록시에서도 이 규칙을 유지하고 외부 모니터링에서 콜백 쿼리 문자열을 수집하지 않습니다.
- 카카오 비밀 값은 권한 `0600`인 외부 자격 증명 파일이나 API 프로세스 환경에 둡니다. 자격 증명 누락, 명시한 콜백 주소 오류, 테스트 데이터 모드에서는 카카오 로그인만 비활성화합니다. 콜백은 `WEB_ORIGIN`과 `/api/v1/auth/kakao/callback`을 조합한 고정 주소이며, 임의의 복귀 URL은 허용하지 않습니다. [카카오 운영 문서](KAKAO_LOGIN.md)를 참고하세요.
- 로그아웃은 Orsem 세션을 무효화하고 새 CSRF 토큰을 가진 익명 세션을 만듭니다. 브라우저의 카카오계정을 로그아웃하거나 공급자 토큰을 폐기하거나 카카오 앱 연결을 해제하지 않습니다.
- 봇 서비스·기기 토큰은 무작위 bearer 토큰이며 서버에는 해시만 저장합니다.
- 쿼리 문자열의 API 키는 로그에 남기지 않습니다. 오류 메시지와 구조화 로그에서 알려진 비밀 값 이름과 bearer 값을 가립니다.
- 토스 자격 증명은 외부 비밀 파일이나 서버 프로세스 환경에 둡니다. REST와 WebSocket은 서버가 소유한 OAuth 토큰을 공유하며 브라우저 응답에 자격 증명, 토큰, 원본 시세 응답을 포함하지 않습니다. 커넥터 자격 증명을 `VITE_*` 변수에 넣으면 안 됩니다.
- 공시 문서는 저장소 밖에 보관하며, 관리자 인증과 허용 경로 검사를 거치는 다운로드 경로로만 제공합니다.
- 원본 ZIP/XML은 신뢰할 수 없는 입력입니다. 파서는 압축·해제 크기, 항목 수, 경로, 중첩 압축 파일, DTD, 외부 엔티티를 제한합니다.

운영 환경에서는 Nginx에서 TLS를 종료합니다. `.env`, `/home/laeti/orsem-data`, MySQL, Redis를 공개 네트워크에서 접근할 수 없도록 유지합니다. 기기를 분실하면 해당 봇 토큰을 즉시 교체합니다.
