# 관심 종목·공유방과 종목 상세 사용법

홈의 시장 뉴스 아래와 **관심기업** 화면은 같은 관심 종목 패널을 사용합니다. 상단에서 **개인** 또는 내가 만들거나 참여한 **공유방**을 선택하고, 아래 그룹 탭을 고릅니다.

## 그룹·종목 편집

1. **그룹 관리**에서 최대 80자의 이름으로 그룹을 만듭니다. 개인 공간과 방마다 최대 20개 그룹을 둘 수 있습니다.
2. **그룹 편집**에서 이름·순서를 바꾸거나 그룹을 삭제합니다. 종목이 든 그룹의 삭제에는 그룹·종목 관리 권한이 모두 필요하며 삭제할 범위를 다시 확인합니다.
3. **종목 편집**에서 기업명·종목코드·티커로 검색해 추가하거나 선택한 종목을 제거합니다. 그룹 전체 최대 200종목을 편집하므로 화면의 21종목 페이지 경계를 넘어 정렬할 수 있습니다.
4. 위아래 버튼 또는 위치 번호를 사용합니다. 위치 번호는 입력 후 Enter 또는 다른 곳을 누르면 적용됩니다. **저장**해야 반영되며 **취소**하면 초안을 버립니다.
5. 다른 사람이 먼저 저장하면 충돌 안내가 나타나고 초안은 유지됩니다. 창을 닫고 다시 열어 최신 목록을 확인한 뒤 편집하세요. 편집 도중 자동 갱신되더라도 편집을 시작한 버전으로 저장 여부를 검사합니다.

그룹 안의 종목은 중복할 수 없고 서로 다른 그룹에는 같은 종목을 넣을 수 있습니다. 개인 그룹 순서는 본인에게, 방 안의 그룹·종목 순서는 모든 참여자에게 적용됩니다. **방 순서**는 내 방 선택 목록만 정리합니다.

그리드·목록 버튼으로 배치를 바꾸고 카드·행 전체를 누르면 종목 상세로 이동합니다. **관심종목으로 돌아가기**는 공간·그룹·보기 방식·페이지를 복원합니다. 종목 상세의 **관심그룹에 추가**에서도 편집 권한이 있는 그룹에 넣을 수 있습니다.

기존 **운영 관심목록** 편집은 종료했으며 국내·미국 각각 시가총액 상위 20개 대표 종목으로 대체합니다. `/watchlist` 아래에서 기준일·순위·다음 갱신을 확인할 수 있습니다. 매월 KST 새 달에 갱신하고 검증에 실패하면 이전 정상 목록을 유지합니다. 회사 이벤트 알림과 봇은 이 월간 목록을 따르며, 개인·방 그룹 편집은 공통 알림 대상을 바꾸지 않습니다. 선정 범위와 자료 계산은 [월간 시장 목록](MONTHLY_MARKET_LEADERS.md)을 참고하세요.

## 공유방 참여와 권한

**공유방 찾기·만들기**에서 방을 만들거나 참여를 신청합니다. 참여 전에는 방 이름·소개·방장 표시명만 보입니다. 방장 또는 방 관리자가 **참여자·설정**에서 승인하면 조회 멤버로 참여합니다. 채팅·댓글·외부 알림은 없습니다.

| 역할·권한 | 할 수 있는 일                                        |
| --------- | ---------------------------------------------------- |
| 방장      | 방 전체 관리, 관리자 지정·해제, 방장 이전, 방 삭제   |
| 방 관리자 | 이름·소개, 참여 심사, 일반 멤버·권한, 그룹·종목 관리 |
| 그룹 관리 | 그룹 생성·이름·순서, 빈 그룹 삭제                    |
| 종목 관리 | 기존 그룹의 종목 추가·제거·순서                      |
| 조회      | 승인된 방의 그룹·종목·참여자 조회                    |

그룹 관리와 종목 관리는 각각 또는 함께 부여합니다. 방 전체에 적용되며 그룹별 권한은 없습니다. 방 관리자는 다른 관리자를 강등하거나 방장을 변경할 수 없습니다. 서비스 관리자도 방 참여 없이 내용을 읽거나 편집할 수 없습니다.

멤버는 탈퇴할 수 있습니다. 방장은 승인된 방 멤버에게 방장을 이전하거나 방을 삭제한 뒤 나갈 수 있습니다. 강퇴·탈퇴·서비스 이용 승인 취소 후에는 접근이 차단됩니다. 방장 이용 승인이 중지되면 방 접근과 해당 방을 통한 수집 대상 반영도 중지됩니다. 변경자·시각은 서버 이력에 남습니다.

개인 그룹의 **공유방에 복사**는 원본을 유지합니다. 복사 후 양쪽의 이름·종목 변경은 독립적이며 대상 방의 그룹·종목 관리 권한이 모두 필요합니다.

이전 공유 그룹은 각자 별도 방으로 이전됩니다. 그룹 ID·종목·순서를 유지하고 소유자는 방장, 기존 팔로워는 조회 멤버가 됩니다. 새 참여부터 승인제가 적용되며 옛 팔로우·전체 회원 공유 API는 종료되었습니다.

## 가격·추이·최근 소식

| 표시          | 의미                                                    |
| ------------- | ------------------------------------------------------- |
| 실시간        | 서버에서 유효한 최신 체결 시세로 판단한 가격            |
| 최근 체결     | 마지막 체결 시각이 표시된 이전 시세                     |
| 종가          | 국내 종목에 당일 시세가 없을 때 확인된 이전 거래일 종가 |
| 시세 대기 / — | 표시 가능한 가격이나 비교 종가가 없음                   |

전일 대비는 **표시한 가격**의 비교 종가로 계산합니다. 국내 종가 대체 시에는 그 종가 직전 거래일과 비교하며, 미국은 기존 체결가 표시 정책을 유지합니다. 비교 기준이 없으면 등락을 만들지 않습니다. 작은 그래프는 최근 최대 20개 완료 일봉 종가이며 두 개 미만이면 기록 부족을 표시합니다.

**최근 7일**은 KST 오늘을 포함한 7일의 접수·발표일 기준입니다. 공시와 이벤트 건수는 별도로 표시하며 합산하지 않습니다. 동일 공시를 반영한 이벤트는 상세의 최신 소식 목록에서 중복 표시하지 않습니다. 실제 발생일은 별도로 표시합니다. 그룹 패널은 보이는 동안 60초마다 최대 21종목을 갱신합니다.

## 종목 상세와 뉴스

종목별 메뉴·차트·코드 주소는 [종목 화면](COMPANY_SCREEN.md)을 따릅니다. 메인은 시장 뉴스 전체 폭 아래에 관심 종목과 내 관심 종목 소식을 PC 2열로, 900px 이하에서는 세로로 배치합니다. `/watchlist`는 시장 뉴스를 표시하지 않고 관심 종목 → 개인 소식 → 월간 시총 목록 순서로 화면 크기에 관계없이 1열로 배치합니다. 월간 목록 내부의 국내·미국 열은 900px 이하에서 세로로 전환합니다. 개인 소식은 관심 종목 카드 높이에 맞추며 제목과 뉴스 / 공시 탭은 고정하고 목록만 스크롤합니다. 본인의 모든 개인 그룹 종목을 합치며 공유방과 다른 회원의 그룹은 포함하지 않습니다.

그룹 추가·삭제·이름 변경·종목 추가·삭제는 **그룹 관리** 창에서 처리합니다. 개인 그룹이 없는 경우에도 같은 창에서 그룹을 만들고 종목 편집으로 이어집니다. 저장은 revision을 검사하며 다른 사용자의 개인 그룹에 접근할 수 없습니다.

메인의 시장 뉴스는 공식 시장 소식과 증시·금리·환율 키워드 검색 결과를 표시합니다. 네이버 원문 링크는 관련 뉴스와 함께 표시하며 정기·종목별 자동 조회는 [뉴스 수집](NEWS_COLLECTION.md) 정책을 따릅니다.
