# MessengerBotR 브리지

이 디렉터리는 Orsem 알림의 Android 측 브리지를 포함합니다. MessengerBotR 0.7.40 이상을 대상으로 하며 API2(`BotManager`, `Event.MESSAGE`, `Bot.send`, `Database`)를 사용합니다.

## 설치

1. MessengerBotR에서 이름이 `orsem`인 API2 봇을 만듭니다.
2. 봇 스크립트에 `orsem-api2.js`를 복사합니다.
3. 봇의 `Database` 디렉터리에 `orsem-config.example.json`을 `orsem-config.json`으로 복사하고 HTTPS Orsem URL을 설정합니다.
4. 인증된 Orsem 대시보드에서 일회용 MessengerBot 연결 코드를 만듭니다. 코드는 10분 뒤 만료됩니다.
5. 알림을 받을 카카오톡 방 하나에서 해당 코드를 넣어 `/오르셈 연결 123456`을 보냅니다.
6. 알림 접근 권한을 켠 상태로 유지하고 봇을 컴파일·시작합니다.

기기 토큰은 MessengerBotR의 비공개 `Database/orsem-state.json`에만 저장하며 서버는 해시만 보관합니다. 스크립트는 토큰을 로그에 남기지 않습니다. 휴대폰을 분실하면 해당 상태 파일을 삭제하고 Orsem에서 기기를 폐기합니다.

## 명령어

- `/오르셈 상태`
- `/오르셈 최근`
- `/오르셈 종목 삼성전자`

연결된 방에서 연결된 발신자 해시에 해당하는 요청만 받습니다. 브리지는 15초마다 전송 대상을 조회하고 60초 동안 점유합니다. 보관량을 제한한 로컬 전송 기록으로 카카오 전송 성공 뒤 수신 확인이 일시적으로 유실되어도 중복 발송을 방지합니다. 카카오 메시지는 편집할 수 없어 감지 알림과 파싱 완료 알림을 별도로 보냅니다.

유효한 인증서가 있는 HTTPS 주소를 사용합니다. `Bot.send`에는 설정된 방의 활성 응답 세션이 필요합니다. 재부팅 뒤 세션 누락으로 전송이 실패하면 해당 방에 카카오톡 메시지를 한 번 이상 보냅니다.
