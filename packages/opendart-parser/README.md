# OpenDART 파서

Orsem에서 사용하는 다섯 가지 지분공시 유형을 처리하는 결정적 파서입니다. `D001`은 대량보유, `D002`는 임원·주요주주 소유변동, `D003`은 의결권 위임 권유, `D004`는 공개매수, `D005`는 향후 거래계획을 다룹니다.

압축 파일 읽기는 전체 압축 파일 50 MiB, 항목 200개, 항목당 50 MiB, 압축 해제 총량 250 MiB로 제한합니다. 경로 이탈, 중첩 ZIP, DTD·엔티티 선언, 지원하지 않는 인코딩, 잘못된 API 오류 응답을 거절합니다. 모든 XML 후보를 확인합니다. CP949/EUC-KR은 BOM 또는 XML 선언으로 인코딩이 식별될 때만 디코딩하며, 해석할 수 없는 데이터는 추측하지 않고 명시적인 오류로 처리합니다.

표는 `rowspan`과 `colspan`을 펼쳐 정규화합니다. 거래 방법은 정확히 일치하는 허용 목록으로 분류하고 `methodRaw`와 경고를 보존합니다. 수량이 양수라는 이유만으로 `MARKET_BUY`로 분류하지 않습니다. 충돌하거나 알 수 없는 방법은 검토를 위해 `UNKNOWN`으로 남깁니다. XML 깊이, 노드, 표, 행, 원본 셀, 펼친 셀, 열 수는 파싱 전후에 각각 제한합니다. 반환하는 파싱 계약은 중첩 객체까지 동결합니다.

저장소의 테스트 데이터는 의도적으로 합성한 자료입니다. 운영 문서에는 규제 대상이거나 재배포에 민감한 자료가 포함될 수 있으므로, 검토를 마친 실제 OpenDART 기준 압축 문서는 외부 원본 저장소에 보관합니다.
